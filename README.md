# 宅建CITY — Railway Webアプリ

宅建学習と街づくりを組み合わせた試作版。Python標準ライブラリのみで起動できます。

## 実装済み

- アカウント登録・ログイン、PBKDF2でのパスワード保存、セッションCookie
- 32問の独自問題・過去問テーマ再構成問題。分野／難易度／問題形式／出題元で絞り込み
- 単一選択と複数選択、解説、間違いの復習
- 初回正解のみ順位点とコインを付与、全国・都道府県・直近7日の公開希望者ランキング
- アバター、年代・立場・都道府県の任意設定、学習順位と街を別々に公開設定
- 12〜24区画の街、コインで敷地拡張、階数の増築、建築様式の改築、有料解体
- 道路・歩道・神社・コンビニなどの景観、拡張時の偶発的な埋設物と埋蔵文化財の調査
- 公開を選んだ街の見学、街ランキング、直近の建築フィード
- 立体座標から描画する街。建物の階数、屋根、窓、道路を反映し、ドラッグ回転とホイール拡大に対応
- 街レベルに応じた発展段階（村→町→市→中核都市→大都市→メガシティ→世界都市→未来都市→グローバル都市）
- 公式試験情報へのリンクと直近5分の利用者数

## 起動

`python server.py` を実行し、`http://localhost:8000` にアクセス。`PORT` 環境変数に対応。

RailwayではVolumeを `/data` にマウントし `DATABASE_PATH=/data/takken.sqlite3` を指定。既存アプリのCookie利用者の匿名回答テーブルは残りますが、新規アカウントへの自動移行はありません。

## 公開前の作業

問題は独自作成の試作品です。法令・正解・解説について宅建試験の現行範囲に照らした校閲が必要です。過去問テーマは公式問題の転載ではありません。実際の過去問原文は公式リンクを開いて確認します。

AI個別指導、決済、パスワード再設定、正式な50問模試は未実装。大量の実利用者を受け入れる前にメール確認、アカウント削除、通報・表示名管理、監視・バックアップ、プライバシーポリシーを追加してください。

街スコアは「各建物の必要コイン×10＋増築階数×80＋建物の種類数×15＋建物数×5」。学習順位点を消費せず、建築コインのみ消費します。街の公開は初期状態でオフです。街レベルは `min(99, 1 + (街EXP + 街スコア) // 100)`。初回正解では順位点と同数の街EXPを得られ、その問題の当日最初の復習正解でも2EXPを得られます。グローバルタウンは現在予告画面のみで、土地売買や競売は未実装です。
